# BestellApp - BurgerHouse

Responsive Lieferdienst-Webseite nach einer Figma-Vorlage. Die Gerichte werden dynamisch aus JavaScript-Objekten gerendert. Der Warenkorb funktioniert auf Desktop und Mobilgeräten.

## Funktionen

- 12 Gerichte in 3 Kategorien, dynamisch über JavaScript gerendert
- Kategorien-Navigation mit Sprunglinks
- Gerichte hinzufügen, Menge erhöhen/verringern und löschen
- Automatische Berechnung von Zwischensumme, Lieferkosten und Gesamtpreis
- Sticky Warenkorb auf dem Desktop
- Warenkorb als Dialog auf mobilen Geräten
- Bestellbestätigung ohne `alert()` mit automatischem Ausblenden
- Responsive bis 320 px und begrenzte Inhaltsbreite für große Bildschirme
- Lokale Bilder und eigenes Favicon

## Projekt starten

`index.html` mit Live Server in Visual Studio Code öffnen oder direkt im Browser starten.
